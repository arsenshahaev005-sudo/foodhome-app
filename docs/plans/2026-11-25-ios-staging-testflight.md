# Food&Home Staging для внутреннего TestFlight

На одном iPhone пользователь сможет открыть Food&Home и Food&Home Staging. Тестовый вариант использует отдельную запись App Store Connect, привязку к тестовому сайту, своё хранилище iOS и свой виджет статуса заказа.

1. Зарегистрировать идентификаторы `market.foodhome.app.staging` и `market.foodhome.app.staging.OrderStatus`. Выпустить два профиля App Store Connect на действующий сертификат команды.
2. Добавить сборочную конфигурацию staging к существующим целям приложения и расширения, отдельное имя и фирменную иконку. Ограничить начальный URL, backend, OAuth callback, ссылки из push и виджета тестовым окружением. Проверить оба варианта тестами iOS.
3. Добавить ручной внутренний выпуск staging из основной ветки. Перед отправкой проверить фактически подписанные bundle ID, entitlements, версию сборки и нужную аудиторию. Использовать существующий защищённый контекст подписи.
4. Создать карточку Food&Home Staging с русской локализацией и группой внутреннего тестирования для владельца. Загрузить подписанную сборку, дождаться обработки в Apple и проверить членство группы и доступ владельца.
