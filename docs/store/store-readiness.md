# Store readiness checklist

This checklist is a public template, not a claim that a release is ready.

- Verify genuine platform value and reliable branded recovery behavior.
- Verify account deletion, privacy policy, support, reporting, blocking, and moderation flows.
- Complete Apple privacy and Google data-safety disclosures from current behavior.
- Validate permission purpose strings and least-privilege entitlement use.
- Exercise push, links, media, location, external handoff, process recovery, and old-shell/new-web compatibility on real devices.
- Keep signing identities, store credentials, and review access outside source control.
- Confirm all automated checks and protected release gates before submission.
